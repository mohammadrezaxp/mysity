# Screenshots

This folder contains screenshots of the Mysity blog platform for portfolio/demo purposes.

## How to Add Screenshots

1. Take screenshots of your running application
2. Name them appropriately:
   - `home.png` - Homepage
   - `blog.png` - Blog listing
   - `post.png` - Single post view
   - `login.png` - Login page
   - `admin.png` - Admin panel
3. Place them in this folder

## Recommended Screenshot Sizes

- Width: 1200px - 1400px
- Format: PNG or WebP
- Keep file sizes under 500KB for faster loading
